# SERJAFAN — Website Bisnis Jasa Pendidikan & Digital Kota Padang

> **"Butuh Jasa? SERJAFAN Aja!"**  
> *"Semua kebutuhan jasa, lebih mudah dalam satu tempat."*

SERJAFAN adalah platform layanan jasa pendidikan dan digital untuk masyarakat Kota Padang, Sumatera Barat. Menyediakan jasa pengetikan, pembuatan PowerPoint, bantuan tugas sekolah & akademik kuliah, olah data Excel & dokumen Word, serta desain poster/flyer dengan harga transparan dan pemesanan langsung melalui WhatsApp.

---

## 🚀 Fitur Unggulan

- **Harga Transparan**: Mulai dari Rp3.000 dengan daftar harga per kategori lengkap.
- **Layanan Express**: Opsi pengerjaan kilat <24 jam (+30%) & <6 jam (+50%).
- **Integrasi WhatsApp Otomatis**: Generator pesan WhatsApp kustom sesuai jenis layanan.
- **Pencarian & Filter Interaktif**: Live search dan filter kategori (*Semua, Pendidikan, Mengetik, Dokumen, PowerPoint, Excel, Desain*).
- **Mobile-First & Responsif**: Dilengkapi bilah navigasi bawah (*Mobile Bottom Nav*) dan modal bottom sheet.
- **Integritas Akademik & FAQ**: Penegasan batas layanan bantuan belajar yang diperbolehkan (tanpa skripsi/ujian).
- **Performa Tinggi**: 100% Native HTML5, CSS3, dan ES Modules tanpa ketergantungan library eksternal berat.

## 💻 Cara Menjalankan Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/irfan111111111/jasa_tugas_serjafan_aja.git
   ```
2. Buka folder projek:
   ```bash
   cd jasa_tugas_serjafan_aja
   ```
3. Jalankan server lokal:
   ```bash
   python -m http.server 3000
   ```
4. Buka di browser: `http://localhost:3000`
